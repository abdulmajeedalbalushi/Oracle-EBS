# Oracle EBS Procurement Cycle – Step-by-Step

### 1. Log in to Oracle EBS

Log in to the Oracle E-Business Suite environment using your assigned user account.

### 2. Assign Responsibilities

Navigate to:

**System Administrator → Security → User → Define**

Search for your user and assign the following responsibilities:

- **Inventory, Vision Operations (USA)**
- **Purchasing, Vision Operations (USA)**
- **Payables, Vision Operations (USA)**
- **General Ledger, Vision Operations (USA)**

### 3. Add the Preparer

Set the preparer/manager information as follows:

- **Person:** Stock, Ms. Pat

Press **Tab**, then select **Save**.

---

## 4. Create the Inventory Item

Navigate to:

**Inventory, Vision Operations (USA) → Items → Master Items**

In the Find window:

- Enter **V%**
- Select **V1 Vision Operations**

Create the following item:

- **Item:** `XX_ABDULMAJEED_LAPTOP`
- **Description:** `LAPTOP FOR CODELINE - MUSCAT`

Go to:

**Tools → Copy From**

Select:

- **Template:** Finished Goods

Click **Apply**, then **Done**.

Open the **Purchasing** tab and enter:

- **List Price:** 100

Save the item.

---

## 5. Add Initial Inventory Quantity

Navigate to:

**Inventory, Vision Operations (USA) → Transactions → Miscellaneous Transactions**

Set:

- **Type:** Miscellaneous Receipt

Open **Transaction Lines** and enter:

- **Item:** `XX_ABDULMAJEED_LAPTOP`
- **Subinventory:** Stores
- **UOM:** Ea (Each)
- **Quantity:** 1000
- **Account:** Account Alias → Employee Exp

Save the transaction.

---

## 6. Check the On-Hand Quantity

Navigate to:

**Inventory, Vision Operations (USA) → On-Hand Availability → On-Hand Quantity**

Enter:

- **Item/Revision:** `XX_ABDULMAJEED_LAPTOP`

Click **Find**, then select **Availability** to view the available quantity.

You can also verify the item in the database:

```sql
SELECT SEGMENT1
FROM MTL_SYSTEM_ITEMS_B
WHERE SEGMENT1 = 'XX_ABDULMAJEED_LAPTOP';
```

Expected result:

```text
SEGMENT1
----------------------------------------
XX_ABDULMAJEED_LAPTOP
```

**Actions → 1**

**Create Accounting → Final Post → OK**

# 14. View the General Ledger Journal

Run the following SQL query:

```sql
SELECT *
FROM GL_JE_HEADERS
WHERE NAME LIKE '%26 Purchase Invoices USD'
ORDER BY 1 DESC;
```

Copy the journal name generated by the system.

For example:

`SEP-26 Purchase Invoices USD`

Then navigate to:

**General Ledger, Vision Operations (USA) → Journal → Enter**

Enter:

- **Journal:** SEP-26 Purchase Invoices USD

Click **Find** to retrieve the journal.
